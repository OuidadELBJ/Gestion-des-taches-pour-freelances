# Application de Gestion de Tâches pour Freelances

Une solution Android native complète conçue pour aider les professionnels indépendants à centraliser la gestion de leurs projets, le suivi de leur temps de travail et le pilotage de leurs finances[cite: 1]. Ce projet a été réalisé dans le cadre du module **Développement Mobile** à l'**ENSIAS**[cite: 1].


## Fonctionnalités Clés

*   **Gestion de Projets & Tâches** : Création, modification et suivi de projets avec gestion des priorités, des statuts (En cours, Terminé, En retard) et des échéances[cite: 1].
*   **Suivi du Temps (Timer)** : Chronomètre intégré pour mesurer précisément le temps passé sur chaque tâche afin de faciliter la facturation et l'analyse de productivité[cite: 1].
*   **Pilotage Financier** : Suivi des paiements reçus et attendus, gestion des budgets et génération automatique de messages de relance (SMS/Email) pour les clients[cite: 1].
*   **Tableau de Bord Intuitif** : Vue d'ensemble des indicateurs clés (KPIs) : nombre de projets actifs, temps total cumulé et revenus du mois[cite: 1].
*   **Mode Offline-First** : Utilisation fluide sans connexion internet grâce à la persistance locale, avec synchronisation automatique dès le retour du réseau[cite: 1].
*   **Système de Notifications** : Rappels configurables pour ne jamais manquer une deadline de projet ou un paiement[cite: 1].

---

## Stack Technique

*   **Langage** : Java 
*   **Architecture** : MVVM (Model-View-ViewModel) avec le pattern
*   **Repository** pour une séparation nette des responsabilités.
*   **Base de données locale** : **Room Persistence Library** (SQLite) pour le stockage interne sécurisé.
*   **Backend & Cloud** : 
    *   **Firebase Authentication** : Gestion sécurisée des comptes utilisateurs.
    *   **Cloud Firestore** : Synchronisation en temps réel et sauvegarde des données sur le cloud.
*   **IDE** : Android Studio.
*   **Versionnage** : GitHub pour la collaboration d'équipe.
